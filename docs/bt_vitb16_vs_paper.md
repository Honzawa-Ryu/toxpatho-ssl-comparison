## 1. モデル・損失

| 項目 | 元論文 | exp 0029 | 区分 | 備考 |
|---|---|---|---|---|
| backbone | ResNet-50（最終分類層なし, 出力 2048） | **ViT-B/16**（timm `vit_base_patch16_224`, `dynamic_img_size`, CLS トークン出力 768） | ⚠️ | 論文は ResNet-50 のみ。ViT への言及なし。**LARS が ViT で安定かは未検証・先行報告も見つからず** |

## 4. データ拡張

論文は強度・確率を書かず BYOL に委ねている。0029 は**本リポジトリの全手法共通パイプライン**（Goal.yaml: 前処理は手法間で統一）で、論文（BYOL 流）とは異なる。

| 変換 | 元論文（BYOL 流・❓未照合） | exp 0029 | 区分 |
|---|---|---|---|
| RandomResizedCrop | 224px, scale (0.08, 1.0)（記憶） | 224px, scale **(0.2, 1.0)** | ⚠️ 病理パッチで微細構造が消えるため |
| 水平反転 | p=0.5 | p=0.5 | ✅ |
| **回転** | なし | **0〜180° 一様, p=1** | ⚠️ 病理は向きに不変 |
| ColorJitter | (0.4, 0.4, 0.2, 0.1), p=0.8 | (0.4, 0.4, 0.2, 0.1), p=0.8 | ✅ |
| Grayscale | p=0.2（記憶） | p=**0.05** | ⚠️ H&E の色は診断的に重要なため低く抑えている |
| Gaussian blur | **非対称**（view1 p=1.0 / view2 p=0.1）, kernel 23（記憶） | **対称** p=**0.4**, kernel 3×3, σ∈(1,2) | ⚠️ |
| Solarization | **非対称**（view1 p=0 / view2 p=0.2）（記憶） | **なし**（p=0） | ⚠️ |
| 正規化 | ImageNet 平均・分散 | 同じ | ✅ |

`--blur_plob` の CLI 既定は 0.4（`ssl_transform` 関数の既定 0.2 を上書きする）。

## 5. 総 step 数の合わせ方

```
論文   : 1000 epoch × floor(1,281,167 / 2048) = 1000 × 625  = 625,000 step
本実験 : floor(800,000 / 2048) = 390 step/epoch
         625,000 / 390 ≈ 1,603 epoch  →  1600 epoch = 624,000 step
warmup : 論文 10 epoch × 625 = 6,250 step → 6,250 / 390 ≈ 16 epoch (= 6,240 step)
```

## 6. 崩壊検知（学習を止める条件）

論文には無い、本プロジェクトの運用上の追加（Goal.yaml 方針3）。

| 条件 | 設定 | 備考 |
|---|---|---|
| NaN / inf の train_loss | 即停止（毎 epoch） | 重みが回復不能。`state.pt` 保存より前に判定 |
| 損失の持続的な跳ね返り | epoch≥20 以降の最小値の **2 倍超が 3 epoch 連続**で停止（`--collapse_loss_rebound 2.0`） | ⚠️ **比率は較正していない**。止める側に倒した |
| effective rank | < 5 が 5 epoch おき × 2 回連続で停止 | 鈍い指標 |
| uniformity | **無効**（`--collapse_ignore_uniformity`） | BT は健全でも ≈0 になりうるため。有効だと ep10 に誤停止しうる |
| **検知できないもの** | 損失が有限のまま高止まりする停滞 | 初回ランの経過は人が確認する |

## 7. 崩壊したときの修正候補（逸脱として記録すること）

1. optimizer: LARS → AdamW（ViT の SSL では AdamW が標準。論文からの大きな逸脱）
2. lr の引き下げ（DINO 0026→0028 で崩壊原因が lr だった前例）
3. augmentation を BYOL 流（非対称 blur・solarization・grayscale 0.2）に寄せる

いずれも**新しい実験番号で、1 点ずつ変えて**記録する。
